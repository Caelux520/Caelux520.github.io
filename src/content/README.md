# 写文章

在 `src/content/posts/` 新建一个 `.md` 文件。文章地址默认由 **标题** 生成：中文会保留，空格和标点换成 `-`。例如标题「我的 Astro 小站笔记」对应 `/posts/我的-astro-小站笔记/`。

如果想自己指定地址，就在 frontmatter 里写 `slug`；以前用文件名生成的旧地址会自动跳到新地址（0 秒跳转页），不会直接 404。

发布后如果还会改标题，建议给这篇文章写上 `slug`，把地址固定下来；不写的话，地址会跟着标题变。

在文件顶部填写文章信息，空行后写 Markdown 正文：

```md
---
title: 文章标题
slug: my-own-url   # 可选：自定义地址尾缀；不写就按 title 自动生成
date: 2026-09-27
desc: 列表和分享卡片中显示的简介
category: 随笔
tags:
  - 日常
cover: /covers/my-note.jpg
draft: false   # true = 草稿，不参与构建列表
---

从这里开始写正文。
```

封面图片放在 `public/` 下，再填写以 `/` 开头的站点路径；`cover` 和 `tags` 都可以省略。文章标题、日期、简介和分类为必填项。分类和标签会自动汇总到归档筛选与侧栏。

### 正文里的图片

图片和普通 Markdown 一样，一行就行：

```md
![樱花壁纸](/walls/1-preview.jpg)
```

- 图片文件放在 `public/` 下（比如 `public/walls/1-preview.jpg`），正文里用 `/walls/1-preview.jpg` 这样以 `/` 开头的路径引用
- 方括号里的是说明文字，会显示在灯箱底部，也方便读屏和 SEO
- 渲染时自动加 `loading="lazy"`（滚到附近才加载）和 `decoding="async"`，大图不会撑破正文栏
- **点图片开灯箱**看原图，同一篇里有多张可以用 `←` `→` 连着翻，`Esc` 或点空白处关闭
- 图片可以套在链接里：`[![说明](/a.jpg)](/b.jpg)`，灯箱和链接各管各的
- 想给图片加标题（鼠标悬停显示），用 Markdown 的 title 语法：`![说明](/a.jpg "标题")`

新增文件后，Astro 会自动生成列表项、详情页、站内搜索数据和 RSS 条目。

不想发布时把 `draft` 设为 `true`：文章不会出现在列表、归档、RSS 和搜索里，也不会生成详情页（直接访问返回 404）。

密码字段仅用于现有的前端演示锁，不能保护真正的私密内容。
